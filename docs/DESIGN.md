# Identidade visual

Referência principal: [protótipo](referencias/prototipo-orcamentos.png), fornecido pelo usuário. A marca COLAR e os dados ilustrativos não são identidade fixa do SaaS: a interface usa os dados da empresa autenticada.

Tokens em `src/app/globals.css`: primária verde-petróleo #008482 (ajuste mínimo da referência para contraste branco >=4,5:1), hover #006b69, texto #111827, secundário #667085, fundo #f4f6f8, superfície branca, borda #e2e7ec, seleção #e5f5f3. Tipografia sem serifa de sistema (referência não permite identificar uma família exata): texto 14–16px, títulos 18–24px, total em negrito. Escala de espaço 4/8/12/16/24/32px, campos/cards raio 6/10px, sombra leve e foco visível verde.

Celular: cabeçalho curto, lista com busca e cards; formulário em cliente → itens → revisão. Botões principais largos e campos rotulados. Desktop: lateral de navegação, formulário amplo e resumo lateral quando aplicável. PDF A4 em preto/branco, tabela e total destacados, logo da empresa.

Estados: hover/foco/pressionado distinguíveis, erro com texto além da cor, carregamento evita submissão dupla, botões desabilitados claros. Sem funcionalidade extra do protótipo (WhatsApp especializado, documento pedido, catálogo). Compartilhamento usa API nativa quando disponível com download como alternativa.
